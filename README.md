# Aeronautics Launcher

Лаунчер для сервера друзей со сборкой **All of Create Aeronautics v2.3**:
Minecraft **1.21.1**, NeoForge **21.1.247**, Windows x64 и macOS Intel / Apple Silicon.

Готовый комплект находится в [**Releases — скачать лаунчер**](https://github.com/susumber1/aeronautics-launcher/releases/latest): скачайте файл
`Aeronautics-Launcher-2.3.1-Windows-macOS.zip`, а не архив исходного кода `Source code`.

## Первый запуск

1. Распакуйте весь архив в отдельную папку.
2. Узнайте у владельца текущий адрес сервера и заранее попросите добавить ваш ник в белый список.
3. Откройте `Play-Windows.cmd` или `Play-macOS.command`. При первом запуске введите адрес
   вида `bore.pub:12345`; он сохранится в `server-address.txt`.
4. В HMCL создайте аккаунт по нику («Offline» / «Без лицензии»). Ник должен точно совпадать
   с записью владельца, включая регистр букв.
5. Откройте «Все сборки» → «Установить модпак» → «Импорт из файла» и выберите
   `Aeronautics-2.3.zip` из распакованной папки. Дождитесь установки Minecraft и NeoForge.
6. Выберите **Aeronautics-2.3** и нажмите **Играть** — после загрузки модов игра
   автоматически подключится к серверу.
7. При первом входе в чате: `/register ВАШ_ПАРОЛЬ`. При следующих: `/login ВАШ_ПАРОЛЬ`.
   Используйте отдельный пароль длиной 8–64 символа без пробелов.

При смене временного адреса закройте HMCL, замените строку в `server-address.txt`
и снова откройте соответствующий файл `Play`. Постоянного сервера этот репозиторий не предоставляет:
ноутбук владельца и сервер должны быть включены.

## Что входит

- Одна сборка Aeronautics v2.3: 221 исходный клиентский мод и NO Singleplayer.
- HMCL 3.16.4, помощник настройки и скрипты запуска.
- Автоматическая установка Java 21 с проверкой SHA-256.
- Автоподключение и одна сохранённая запись сервера; одиночная игра скрыта.
- При подключении к серверу владельца — TPS и MSPT под списком игроков по Tab.

Пользователь с доступом к файлам своего компьютера может изменить настройки HMCL.
Ограничение доступа к серверу обеспечивается его белым списком и DirectAuth.

Комплект не содержит мира, аккаунтов, паролей, журналов и файлов управления сервером.
Адрес передаётся владельцем отдельно. Соединение офлайн-сервера не шифруется:
не используйте пароль от почты или других сервисов.

## Совместимость

macOS Apple Silicon: проверены запуск модпака и вход в серверный мир.
Windows x64 и macOS Intel: подготовлены соответствующие скрипты и Java,
но запуск на этих устройствах пока не проверен.
Первый запуск требует интернета. Java для игры: 21; лимит памяти клиента: 5 ГБ.

Если macOS не открывает `.command`, можно запустить `bash Play-macOS.command`
из Терминала в распакованной папке. Если окно закрывается с ошибкой, сохраните
текст сообщения; не отправляйте файлы аккаунтов и пароли.

## Сборка релиза

Нужны Python 3.11+ и JDK 21 (`JAVA_HOME` или `javac`/`jar` в PATH).
Возьмите `Aeronautics-2.3.zip` из предыдущего релиза и официальный
[HMCL 3.16.4](https://github.com/HMCL-dev/HMCL/releases/tag/v3.16.4).

```sh
python3 build.py --modpack /path/to/Aeronautics-2.3.zip --hmcl /path/to/HMCL-3.16.4.jar
```

Скрипт проверит HMCL, скомпилирует помощник и создаст ZIP с SHA-256 в `dist/`.
Большие архивы публикуются в Releases и не хранятся в Git.
